# Karibu KE

Location-based dating demo for Kenya. Built as a static site for **GitHub + Netlify**.

## What this version includes

- Landing page and Kenyan localization (counties, modes, Sheng-friendly copy)
- Profile create/edit stored in the browser (`localStorage`)
- Discover feed with county, mode, distance, and interest filters
- Like / pass / match
- In-browser chat after a match
- Geolocation permission hook
- Report + safety notes
- Premium called out as a roadmap (M-Pesa later)

## What a production app still needs

Real auth, a database, photo storage, matching API, WebSockets, push, and M-Pesa.

## Deploy

Import this repo in Netlify. Publish directory is the repo root.
